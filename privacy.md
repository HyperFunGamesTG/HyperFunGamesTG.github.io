**Wild Run Hyper Rush — Privacy Policy**
Last updated: [date] · Developer: [your name / GeekyOnAi] · Contact: [support e-mail]

1. **What the game collects.** The game has no accounts, names or chat. It uses:
   - An anonymous player ID (Unity Gaming Services) to keep scores on the leaderboards (with the animal and cosmetics
     used) and an optional cloud backup of game progress.
   - Anonymous gameplay statistics only if the player turns on "Anonymous stats" in Settings (never for players under 13).
   - Advertising: Unity LevelPlay and its ad partners may collect the device advertising ID, approximate location
     (from the IP address), device information and ad interactions to show and measure ads.
   - Purchases are processed by Google Play; the game only receives whether "Remove ads" was bought.
2. **Children.** The game asks for the year of birth once (neutral screen) and stores only "under 13" or "13 or over".
   Players under 13 get child-directed ads (no personalized advertising, COPPA flags) and no statistics.
3. **Sharing.** Data is shared only with the providers above to run the game and its ads: Unity Technologies
   (Unity Gaming Services, Unity LevelPlay) and the ad networks enabled in LevelPlay [list them].
4. **Your choices.** Turn statistics off in Settings, reset your advertising ID in the Android settings, or buy
   "Remove ads". To delete leaderboard and cloud data, write to [support e-mail] with the tag shown in the ranking.
5. **Security and retention.** Data travels encrypted (HTTPS) and is kept only while needed for these purposes.
6. **Changes.** Updates to this policy are published at this address.
